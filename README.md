# Nutrition Articles Search Engine

An information retrieval project over health and nutrition articles.

## What it does
- functions.py cleans text with NLTK (stopword removal, Porter stemming) and sets up PyTerrier.
- A Flask app (test_app.py) serves a search form and a results page.
- queries.csv holds the test queries; project.ipynb has the experiments.

## Files
corpus.csv, queries.csv, test.csv, functions.py, project.ipynb, test_app.py, templates/
